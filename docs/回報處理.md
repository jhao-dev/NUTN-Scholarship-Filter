# 資料錯誤回報怎麼處理

網站上的「回報資料錯誤」會開一則標題為「資料錯誤：公告名稱」的 issue（公開、不含個人條件）。

## 多久看一次

每週一次。查看未處理的回報：

```bash
gh issue list --repo jhao-dev/NUTN-Scholarship-Filter --search "資料錯誤 in:title"
```

## 每一則怎麼修

1. 打開公告原文，確認哪裡判斷錯（截止日、戶籍、成績、金額、是否該顯示）。
2. 在 `tests/test_scraper.py` 加一個用公告原句寫的測試，先確認它會失敗。
3. 修改 `scraper/scrape.py`（外部資源改 `scraper/external.py`）。`app.py` 維持原樣。
4. 執行 `python -m unittest discover tests`，全部通過再合併。
5. 下一次自動更新後到網站確認，回覆並關閉 issue。

公告原文本身寫錯或沒寫清楚的，在 issue 說明後關閉，不改規則。

## 通知測試

GitHub 專案頁面 → Actions → Update scholarship data → Run workflow → 勾選「只寄一封測試通知」。
或用指令：

```bash
gh workflow run update-data.yml --repo jhao-dev/NUTN-Scholarship-Filter -f test_notify=true
```
